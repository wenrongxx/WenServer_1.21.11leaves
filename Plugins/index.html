EssentialsX

传送 · 家 · 经济 · 基础命令

生存服的「生活工具箱」：设家、传送请求、公共传送点、转账记账、牌子商店。没装它很多基础命令都不存在。

机制与命令

场景命令要点
家/sethome [名] · /home [名] · /delhome · /renamehome多家要权限节点 + 数量节点
传送请求/tpa /tpahere /tpaccept /tpdeny /tpauto /tpacancel默认 120 秒超时，最多 5 条排队
强传 / 返回/tp /tphere /back /spawn可配延迟与冷却
公共点/setwarp /warp /delwarp /warpinfo可按 warp 分权限
经济/balance /pay /eco give|take|set|reset /balancetop可接 Vault 外部经济
商店/worth /sell /setworth；牌子 [Buy]/[Sell]/[Trade]扣款走 Vault

家上限默认：普通 3 / VIP 5 / 管理 10；无限用 essentials.sethome.multiple.unlimited。

怎么用（新手）

  1. 安家
    站好位置输入 /sethome。要第二个家就命名：/sethome 矿洞。
  2. 回家 / 回死亡点
    /home 或 /home 矿洞；死了用 /back。
  3. 找朋友
    /tpa 朋友名，对方输 /tpaccept。拒绝用 /tpdeny。
  4. 设公共传送
    管理员 /setwarp 商城，玩家 /warp 商城。
  5. 用钱
    看余额 /balance；转账 /pay 对方 50；管理发钱 /eco give 玩家 100。

常见坑

  • 多家要同时有 essentials.sethome.multiple 和 ...multiple.等级，少一个仍只能 1 个家。
  • Warp 默认人人能去；要按点限权再开 per-warp-permission。
  • /pay 有最低金额；透支要 essentials.eco.loan。
  • 别的插件也占了同名命令时，看 overridden-commands。

LuckPerms

权限与用户组

权限总管：谁能用什么命令、显示什么前缀、属于哪一组。Bungee/Velocity 跨服也可用。

核心概念

概念含义
权限节点字符串，true / false / 未设；* 通配
Group权限打包；用 parent 继承（组套组、人挂组）
Track只做升降级轨道（promote），不负责继承
Meta前缀/后缀/自定义键值

常用命令

任务命令
授权限/lp user|group <名> permission set <节点> true|false（另有 unset / check）
挂组... parent add|remove|set <组>
前缀... meta setprefix 100 "&a[VIP]"
升降级/lp user <人> promote|demote <track>
建轨道/lp createtrack staff → lp track staff append helper
调试/lp verbose record <人> → 让他执行 → paste

怎么用（服主）

  1. 先给自己管理
    控制台：lp user 你的ID permission set luckperms.* true（装好后默认没人有 LP 权限）。
  2. 建组
    lp createtrack staff；lp track staff append helper 再 append mod。
  3. 给 VIP 多家
    lp group vip permission set essentials.sethome.multiple true 以及 ...multiple.vip true。
  4. 加前缀
    lp group vip meta addprefix 100 "&6[VIP]"（数字大者优先显示）。
  5. 加人 / 升级
    lp user 张三 parent add vip；升级 lp user 张三 promote staff。

常见坑

  • Track 只管升降级；真正给权限靠 parent 继承。
  • 时长大小写敏感：1M 是一月，1m 是一分钟。
  • 前缀数字越大越优先；多组冲突看 setweight。

CoreProtect

查证与回滚

方块「监控 + 撤销」：谁挖了什么、箱子里少了啥，可查可回滚。反破坏神器。

命令一览

命令作用
/co inspect（/co i）手查模式：点方块看改动
/co lookup（/co l）只查不改；默认全服范围
/co rollback（/co rb）回滚
/co restore（/co rs）恢复（撤销回滚）
/co undo反着做上一次 rb/rs
/co near等于 r:5
/co purge t:30d清旧日志

时间 t:30s/5m/7h/2d/1w，可组合 5d2h、区间 1h-2h。
过滤 u:玩家 · r:10（回滚默认半径 10）/ r:#global / r:#worldedit · a:+block|-block|container|kill|command|sign · i:物品 · e:生物 · f:文本。
附加 #preview · #count · #summary · 翻页 /co l 2。

怎么用（管理员）

  1. 手查
    /co i 后左键可疑方块，看谁改的。
  2. 查失窃
    /co lookup u:可疑ID t:1d a:-block i:diamond_ore。箱内要用 a:container。
  3. 处理熊孩子
    先 /co rollback u:熊孩子 t:2h r:20 #preview 预览。
  4. 真回滚
    确认后去掉 #preview。回多了 /co undo 或 /co restore。
  5. 清理
    定期 /co purge t:30d，防日志占满磁盘。

常见坑

  • lookup 默认全服；rollback 默认身边 10 格。不写 r: 易查爆或回错范围。
  • 务必先 #preview；r:#global 要极谨慎。
  • 时间必须带单位（t:1 不合法）。
  • 箱内物品用 a:container，不能只查 a:block。
分类：CoreProtect
