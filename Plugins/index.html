首页 › EssentialsX

EssentialsX

传送 · 家 · 经济 · 基础命令

生存服的「生活工具箱」：设家、传送请求、公共传送点、转账记账、牌子商店。没装它很多基础命令都不存在。

机制与命令

场景命令要点
家/sethome [名] · /home [名] · /delhome · /renamehome多家要权限节点 + 数量节点
传送请求/tpa /tpahere /tpaccept /tpdeny /tpauto /tpacancel默认 120 秒超时，最多 5 条排队
强传 / 返回/tp /tphere /back /spawn可配延迟与冷却
公共点/setwarp /warp /delwarp /warpinfo可按 warp 分权限
经济/balance /pay /eco give|take|set|reset /balancetop可接 Vault 外部经济
商店/worth /sell /setworth；牌子 [Buy]/[Sell]/[Trade]扣款走 Vault

家上限默认：普通 3 / VIP 5 / 管理 10；无限用 essentials.sethome.multiple.unlimited。

怎么用（新手）

  1. 安家
    站好位置输入 /sethome。要第二个家就命名：/sethome 矿洞。
  2. 回家 / 回死亡点
    /home 或 /home 矿洞；死了用 /back。
  3. 找朋友
    /tpa 朋友名，对方输 /tpaccept。拒绝用 /tpdeny。
  4. 设公共传送
    管理员 /setwarp 商城，玩家 /warp 商城。
  5. 用钱
    看余额 /balance；转账 /pay 对方 50；管理发钱 /eco give 玩家 100。

常见坑

  • 多家要同时有 essentials.sethome.multiple 和 ...multiple.等级，少一个仍只能 1 个家。
  • Warp 默认人人能去；要按点限权再开 per-warp-permission。
  • /pay 有最低金额；透支要 essentials.eco.loan。
  • 别的插件也占了同名命令时，看 overridden-commands。

首页 › LuckPerms

LuckPerms

权限与用户组

权限总管：谁能用什么命令、显示什么前缀、属于哪一组。Bungee/Velocity 跨服也可用。

核心概念

概念含义
权限节点字符串，true / false / 未设；* 通配
Group权限打包；用 parent 继承（组套组、人挂组）
Track只做升降级轨道（promote），不负责继承
Meta前缀/后缀/自定义键值

常用命令

任务命令
授权限/lp user|group <名> permission set <节点> true|false（另有 unset / check）
挂组... parent add|remove|set <组>
前缀... meta setprefix 100 "&a[VIP]"
升降级/lp user <人> promote|demote <track>
建轨道/lp createtrack staff → lp track staff append helper
调试/lp verbose record <人> → 让他执行 → paste

怎么用（服主）

  1. 先给自己管理
    控制台：lp user 你的ID permission set luckperms.* true（装好后默认没人有 LP 权限）。
  2. 建组
    lp createtrack staff；lp track staff append helper 再 append mod。
  3. 给 VIP 多家
    lp group vip permission set essentials.sethome.multiple true 以及 ...multiple.vip true。
  4. 加前缀
    lp group vip meta addprefix 100 "&6[VIP]"（数字大者优先显示）。
  5. 加人 / 升级
    lp user 张三 parent add vip；升级 lp user 张三 promote staff。

常见坑

  • Track 只管升降级；真正给权限靠 parent 继承。
  • 时长大小写敏感：1M 是一月，1m 是一分钟。
  • 前缀数字越大越优先；多组冲突看 setweight。
分类：LuckPerms
首页 › CoreProtect

CoreProtect

查证与回滚

方块「监控 + 撤销」：谁挖了什么、箱子里少了啥，可查可回滚。反破坏神器。

命令一览

命令作用
/co inspect（/co i）手查模式：点方块看改动
/co lookup（/co l）只查不改；默认全服范围
/co rollback（/co rb）回滚
/co restore（/co rs）恢复（撤销回滚）
/co undo反着做上一次 rb/rs
/co near等于 r:5
/co purge t:30d清旧日志

时间 t:30s/5m/7h/2d/1w，可组合 5d2h、区间 1h-2h。
过滤 u:玩家 · r:10（回滚默认半径 10）/ r:#global / r:#worldedit · a:+block|-block|container|kill|command|sign · i:物品 · e:生物 · f:文本。
附加 #preview · #count · #summary · 翻页 /co l 2。

怎么用（管理员）

  1. 手查
    /co i 后左键可疑方块，看谁改的。
  2. 查失窃
    /co lookup u:可疑ID t:1d a:-block i:diamond_ore。箱内要用 a:container。
  3. 处理熊孩子
    先 /co rollback u:熊孩子 t:2h r:20 #preview 预览。
  4. 真回滚
    确认后去掉 #preview。回多了 /co undo 或 /co restore。
  5. 清理
    定期 /co purge t:30d，防日志占满磁盘。

常见坑

  • lookup 默认全服；rollback 默认身边 10 格。不写 r: 易查爆或回错范围。
  • 务必先 #preview；r:#global 要极谨慎。
  • 时间必须带单位（t:1 不合法）。
  • 箱内物品用 a:container，不能只查 a:block。
分类：CoreProtect
首页 › QuickShop-Hikari

QuickShop-Hikari

箱子商店

对着箱子开「自助收银店」：设定商品、买价/卖价，顾客点箱子交易。适合主城摆摊。

怎么开店

  1. 放箱子
    在你有权建造的地方放一个箱子。
  2. 手持商品建店
    手里拿着要卖的东西，对箱子输入：/qs create <数量> <买价> <卖价>。只卖不收写卖价 0（如只出售：B 10 : S 0 写法按插件提示）。
  3. 把货放进箱子
    库存就是箱子里的物品。箱上可显示虚拟展示物。
  4. 顾客怎么买
    左键看信息；右键购买；潜行右键向你出售（是否开放看配置）。
  5. 日常管理
    /qs price 改价 · /qs info 库存 · /qs remove 拆店 · /qs setowner 让店 · /qs unlimited 无限货（管理）。

建店费、税率、每人店数在 config 配；大服建议 MySQL。

常见坑

  • 领地未放行 → 开不了店或交易失败。
  • 买价/卖价写反会亏本。
  • 与 ChestShop 同装容易抢箱子事件，建议只用一个。
  • 税收到手 ≠ 牌面价。
分类：商店
首页 › ChestShop

ChestShop

牌子商店

经典「告示牌 + 箱子」商店。牌子写清买卖价，玩家点牌子交易。

牌子四行怎么写

行内容
第 1 行物品名（可留空 = 手持物品）
第 2 行数量（如 16）
第 3 行B 购价 : S 售价
第 4 行店主名（有效玩家 ID）

怎么用

  1. 放箱子在牌子旁边/后面，手持续商品。
  2. 插牌按上表写满四行，创建成功会有提示。
  3. 进货把商品放进箱子。
  4. 交易右键买、左键卖（以本服配置为准）。
  5. 权限ChestShop.shop.create / .buy / .sell；管理 ChestShop.Admin。

常见坑

  • 物品名或行数写错会拒建；第 4 行必须是真实玩家名。
  • 领地锁箱子却没给插件权限 → 交易失败。
  • 到手金额被税扣掉，和牌子价不一致。
  • 与 QuickShop 同装冲突高，二选一。
分类：商店
首页 › BlueMap

BlueMap

3D 网页地图

浏览器里看服务器 3D 地图：找朋友建筑、看地形、搜标记。

怎么用

  1. 玩家打开网页
    浏览器访问 http://服务器IP:8100（默认端口 8100）。
  2. 浏览
    拖动、缩放、点标记；建筑内部可切洞穴/楼层视图。
  3. 管理重载
    /bluemap reload 改完配置后执行。
  4. 全量重渲
    大改地图后 /bluemap fullrender <map>（很吃 CPU/磁盘，避开高峰，别中途强关）。
  5. 对外访问
    防火墙/反向代理放行 web 端口；可配多世界、分辨率、POI。

常见坑

  • 8100 未放行或被占用 → 外网打不开。
  • 只渲染已生成区块；没探索过的地方是空的，不是坏了。
  • 关「实时玩家」标记可保护行踪。
分类：地图
首页 › AuthMe

AuthMe

登录 · 注册 · 防盗号

进服先验证身份。未登录时不能聊天、不能动、强制生存；注册登录后才恢复完整权限。支持邮箱找回与二步验证。

命令

场景命令
注册/register 密码 确认密码（/reg）
登录/login 密码（/l /log）
改密/changepassword 旧 新（/cp）
注销 / 退出/unregister 密码 · /logout
邮箱找回/email show|add|change|recover|code|setpassword|confirm
二步验证/totp code|add|confirm|remove（/2fa）
管理/authme register|unregister|forcelogin|password 等

怎么用（新手）

  1. 首次进服
    /register 你的密码 再输一遍，两次必须一致。
  2. 以后每次
    /login 密码 后才能玩。
  3. 绑邮箱
    /email add 邮箱 后 /email confirm；丢号用 /email recover。
  4. 改密
    /cp 旧密码 新密码。
  5. 可选 2FA
    /totp add 绑定验证器。

常见坑

  • 密码两次不一致会拒注；特殊字符看服规。
  • 默认禁止多开小号；AntiBot 可临时拦新号。
  • 忘密优先邮箱找回，再找管理重置。
分类：账号
首页 › 自定义附魔

自定义附魔

ExcellentEnchants · AdvanceEnchantmentX

两套自定义附魔：杰出附魔偏原版扩展；高级附魔是中文 GUI 附魔台。可叠出很强装备，注意平衡。

ExcellentEnchants

  • 75+ 附魔；来源：附魔台、村民、战利品、钓鱼、怪装。
  • 品质：普通 / 勇者 / 史诗 / 神话。
  • 命令：/book · /randombook · /givefuel · /disenchant。
  • 依赖前置 nightcore。

AdvanceEnchantmentX

  • /enchanter 打开 GUI；普通约 40%/10 级经验，神级约 1%/75 级。
  • 每件默认最多 5 条自定义附魔。
  • 武器：闪电打击、生命窃取、流血、处决、连击。
  • 镐：范围挖掘 3×3/5×5/6×6、矿脉挖掘、自动熔炼。
  • 甲：荆棘增强、冰/火光环、减伤；特殊：传送打击、陨石打击、时间扭曲、神之模式。

怎么用

  1. 手持装备 → /enchanter，或走附魔台/村民书。
  2. 看清品质与经验花费再确认。
  3. 管理发书：/book 玩家 附魔名 等级；拆解 /disenchant。

常见坑

  • 神之模式、陨石打击、时间扭曲、6×6 范围挖掘极易超模，PVP 建议限制。
  • 两套同装会叠词条；村民/钓鱼也能出自定义书。
分类：附魔
首页 › SimpleVoiceChat

SimpleVoiceChat

游戏内语音

附近玩家语音，可开群组开黑。客户端必须装同版本 mod 才能听/说。

项说明
命令/voicechat
权限voicechat.listen / speak / groups / admin
群组与附近语音是两套音量/范围
说话默认按键说话（客户端绑 PTT）

怎么用

  1. 安装客户端 Simple Voice Chat mod。
  2. 进服 /voicechat 测试。
  3. 按键设置里绑定说话键，按住说话。
  4. 开黑：创建/加入语音群组。
  5. 没声：查 mod 版本、权限、UDP 防火墙、静音。

常见坑

  • 只装服务端没装客户端 mod = 完全听不到。
  • 入群 ≠ 全球对讲；无 listen/speak 会单向或全哑。

首页 › Dominion

Dominion 领地

圈地 · 成员 · 权限标志

中文领地插件。用 /dominion 或 /dom 打开菜单，圈地后保护建筑不被拆、箱不被偷。

怎么标一块地

  1. 快速圈地
    /dom →「创建领地」→ 以你为中心自动圈一块。
  2. 或两点框选
    选第一点 → 选第二点（同世界）→ 创建。适合矩形基地。
  3. 起名
    不能含空格和 . § & ~ ,。可能扣钱（接经济时）。
  4. 注意上限
    领地数量、长宽高、Y 范围有上限；不能与别的领地/出生点重叠。子领地须在父领地内。

成员与权限（flag）

  • 添加成员：好友可进领地；再配「成员权限」或权限组（如「朋友」开箱+开门）。
  • 访客：没加的人只吃访客权限——建议关 break / place / chest。
  • 环境 flag：关苦力怕炸、TNT、火焰蔓延、怪物生成等。
  • 删除/转让要二次确认，不可撤销。

命令参数以 /dom 补全为准。

分类：领地
首页 › TAB · 侧边栏

TAB · ScoreboardPL

Tab 列表与侧边栏

TAB 管按 Tab 的玩家列表、头顶名、Ping；ScoreboardPL 管右侧侧边栏。本服 TAB 里侧栏关着，避免叠两层。

玩家会看到什么

  • Tab 顶/底横幅 + 玩家列表 + Ping；头顶名字按权限组排序。
  • 侧栏：名、等级、血量、食物、钱、坐标、时间、在线/TPS 等。
  • /scoreboard toggle（别名 sb）开关侧栏。

管理怎么配

  1. TAB
    改 header-footer 文案；sorting-types 的组名要与 LuckPerms 组一致。
  2. ScoreboardPL
    改 title、lines（最多 15 行）；支持 %vault_*、%luckperms_* 等占位符。
  3. 时区
    建议改成 Asia/Shanghai。
  4. 重载
    /tab reload · /scoreboard reload。

常见坑

  • 没装 Vault/LuckPerms 时占位符显示成原字面量。
  • 侧栏超过 15 行会截断；两插件都开侧栏会重叠。

首页 › Veinminer

Veinminer 连锁挖矿

挖一块 · 整条矿脉碎

挖矿脉里任意一块，相连同类方块一起碎。另有附魔附属「连锁采矿」。

怎么挖

  1. 对矿脉正常挖掘其中一块（默认原版矿）。
  2. 条件满足时整条一起碎、一起掉。
  3. 默认不用潜行；若服主开了 mustSneak 则须按住潜行。
  4. 工具要挖得动（默认 needCorrectTool：镐挖矿、斧砍原木）。

命令与默认限制

命令作用
/veinminer blocks add|remove改可连锁方块表
/veinminer groups按组限制方块+工具
/veinminer settings全局开关与数值
/veinminer toggle全服开/关
  • maxChain 默认约 100 块/次；冷却约 20 刻。
  • 耐久按块扣；可配每块饥饿。
  • 附魔版开着时，没有「连锁采矿」附魔的工具不会连锁。

常见坑

  • 大矿脉一次掉太多会卡，调低 maxChain。
  • 工具挖不动的方块连锁也不掉（除非关 needCorrectTool）。
分类：采集
