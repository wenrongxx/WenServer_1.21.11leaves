# 致命地牢 Wiki — GitHub Pages 站点

**Deadly Deadly Dungeon**

本目录是 GitHub Pages 的部署根，只含网页所需文件。

## 结构

```
web/
├── index.html
├── assets/app.css
├── .nojekyll
└── README.md
```

## 部署

把 **web/** 里的内容推到仓库根，Settings → Pages 选 main/(root)。

数据包源文件在上级 `SOURCE.txt` 指向的位置，不需要上传到 Pages。
