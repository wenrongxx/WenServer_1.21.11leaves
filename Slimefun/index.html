粘液科技（Slimefun）

Slimefun 4 · 2026.07 · 完整玩法百科

粘液科技（Slimefun）把 Minecraft 从「砍树挖矿」扩展成一条完整的科技树：用原版材料在强化工作台等专属机器里造出粉碎机、发电机、电缆、货运、机器人、魔法装备等。物品通过 NBT 标识，不能用原版合成表「拼样子」做出来——必须在指南书里查看配方，放进粘液机器执行。

本服主体版本 2026.07，界面语言 zh-CN。附属分官方附属与社区附属两大类，详见 官方附属 / 社区附属。

为什么叫「粘液」科技

  • 早期核心材料与史莱姆有关，且整条工业线围绕「把矿物变成更高纯度材料」展开。
  • 玩法主循环是：采集原料 → 解锁研究 → 机器加工 → 发电/物流自动化 → 更高级机器与装备。
  • 与 mcMMO（技能成长）、墓石地牢（冒险掉落）可叠加：地牢打到的矿与材料可直接进粘液产线。

快速入门

从零到第一条自动化产线

阶段 0：领指南书

  • 首次进服自动获得粘液科技指南（本服 receive-on-first-join: true）。丢失可用 /sf guide 补发。
  • 右键打开：左侧是分类（基础、工具、机器、电力、货运、魔法、各附属…），右侧是配方与研究状态。

阶段 1：强化工作台（一切的入口）

  1. 做「强化工作台」
    材料常见为铁砧 + 原版方块组合（以指南为准）。把它当作粘液专用的 3×3 合成台。
  2. 认识三种「台子」
    强化工作台：静态摆格子配方。机器：有进度条、耗电/耗时。多方块：按图用原版方块搭出来（如高炉类），作弊 /sf cheat 拿不到多方块成品。
  3. 解锁「基础」类研究
    经验值解锁（本服不用游戏币）。失败率 1%（硬核附属），失败可再试。解锁有烟花与动画。

阶段 2：第一桶「科技材料」

步骤大致目标说明
1. 粉碎粉碎机 / 手磨原版矿 → 矿粉，提高出货量
2. 洗矿淘金盘 / 洗矿机从沙砾/矿粉再筛出副产物（本服矿研磨机为旧版逻辑）
3. 熔炼电炉 / 冶炼炉矿粉 → 锭；做粘液合金、铜/锡/银等扩展锭
4. 电路基础/高级电路板几乎所有中后期机器的门槛材料

阶段 3：电力与自动搬运

  • 煤发电机或太阳能 → 粘液电缆 → 机器；中间加电容器缓冲。
  • 货运节点贴在箱子/机器上，用货运管理器设频道、过滤器、优先级，实现无人值守。
  • 网络规模上限 200 节点/网络（本服）；可视化可开。

阶段 4：选一条支线

路线抓手
农业美食异域花园 果树 + 美食家 烹饪与完美食物
刷怪工业电力刷怪笼 + 灵魂罐
工具军火粘液匠魂 强化 / Bump 魔法武器 / 战争工艺
超平坦基建神秘科技 填充棒、海绵棒、区块加载器

详细系统说明从 材料与加工 起，数值都尽量对齐游戏内指南与本服 plugins/ 配置。

研究系统

用经验买下整棵科技树

粘液物品默认未研究 = 不可合成/使用。点指南里的「研究」消耗经验等级解锁一整条相关配方。研究不是扣材料，而是扣你的 XP 等级。

本服规则（含硬核粘液）

项数值 / 行为
解锁消耗经验等级（use-money-unlock: false）
经验→游戏币换算25（仅当改用游戏币解锁时生效）
创造模式免费解锁
解锁反馈消息「成功解锁研究」+ 可选烟花；学习动画可关
研究失败1%，提示「研究失败! 你需要再试一次」
死亡随机丢研究关闭
死亡全清研究0%
安卓/机器人故障概率 0%；故障持续 30 秒（若开启）
经验不足提示「你没有足够的经验来解锁这个研究」

研究费用有多贵

  • 本服 Researches.yml 中研究 cost（等级）大致在 1～150，多数 < 50 级，平均约 22 级。
  • 前期基础研究约 1～10 级；中期机器 5～20 级；后期/附属大件可到数十级甚至更高（以指南书实时显示为准）。
  • 覆盖分类包括：主体 slimefun，以及异域花园、美食家、神秘科技、Bump、战争工艺、染色背包、电力刷怪笼、自定义等附属研究组。

首页 › 电力系统

电力系统

产电 → 传输 → 缓冲 → 耗电
  1. 发电
    发电机把燃料/阳光转成能量（单位习惯称 J）。指南「发电机」图例可查燃料表。
  2. 传输
    用粘液电缆把发电机、电容、机器连成同一网络。注意线缆与节点数量。
  3. 缓冲
    电容器储存能量，避免机器瞬间缺电。自定义电容见 自定义内容。
  4. 耗电
    加工机、充能台、货运、机器人、电力刷怪笼等都在耗电端。

网络与诊断

  • 本服网络 max-size: 200；可视化 enable-visualizer: true；多余物品默认不删除。
  • 万用表提示格式：「已储存的能源: 当前 / 容量」。
  • 排障顺序：发电是否在跑 → 电缆是否连贯 → 电容是否满/空 → 机器是否断电停工。

首页 › GPS 与传送

GPS 与传送

  • GPS 网络记录航点，本服上限 21 个。
  • 可设公共传送点并用 /sf teleporter 查看他人公共点。
  • GPS 复杂度会限制高级设备：例如神秘科技每个区块加载器约需 7500 复杂度。
  • 玩法：主城、矿场、刷怪塔、农场各留航点；复杂度攒够再上加载器做离线产线。

首页 › 机器人

机器人（Android）

把重复劳动交给可编程方块
  • 粘液「安卓」按程序做采矿、伐木、农耕、屠宰等循环任务，耗电运行。
  • 需要先研究并合成机器人部件/机身，再在指南中选行为。
  • 故障（硬核粘液）：本服概率 0%；若开启，故障持续约 30 秒后恢复。
  • 领地限制：在你没有权限的地皮/领地里机器人会自动暂停，避免拆家。
  • 与货运联用：机器人采完直接进节点入箱。

首页 › 放射性

放射性

铀与核材料的职业危害

本服 enable-radiation: true，且 burn-players-when-radioactive: true。携带/靠近高放射材料会累计辐射暴露（动作条显示「辐射暴露等级：当前/100」）。

参数本服
辐射更新间隔1
宽限期15
满暴露惩罚可导致玩家燃烧

安全操作

  • 铀、钍及核燃料链放隔离仓库，不要贴身放背包。
  • 穿粘液防护/蜂套等具备抗性的装备再开反应堆线（见指南防护向物品）。
  • 暴露等级升高先离开材料源，利用宽限期恢复。

异域花园 ExoticGarden

灵魂罐 SoulJars

  • 击杀目标生物后用灵魂罐吸取灵魂；本服几乎所有生物统一 128 灵魂 / 罐。
  • 支持列表极广：从蝙蝠、蜜蜂到远古守卫者、劫掠兽、村民、凋灵骷髅等。
  • 玩法：刷怪塔稳定供灵；满罐用于生成/交易/合成向材料。建议先垄断 2～3 种高价值灵。

矿石块 SlimefunOreChunks

  • 启用铁、金、铜、锡、银、铝、铅、锌、镁、镍、钴等矿石块地质资源。
  • 玩法：地质探矿 + 粉碎扩产，减少「全靠手挖」瓶颈。

电力刷怪笼 ElectricSpawners

  • 耗电刷指定怪物（本服 25 种）：僵尸、骷髅、苦力怕、末影人、末影螨、岩浆怪、守卫者、马、铁傀儡、村民、女巫、凋灵骷髅等。
  • 玩法：灵魂罐材料站；务必接货运清掉落，控制实体上限。

  • 区块加载器：每人最多 8 个；每个约需 GPS 复杂度 7500。

战争工艺 SlimefunWarfare

自定义内容（SlimeCustomizer）

服主配置的物品与机器

本服装有 SlimeCustomizer，可用 YAML 添加自定义粘液物品、发电机、机器、电容、生物掉落、地质资源与研究。当前目录里以示例模板为主，可按文档扩成服内活动物品。

配置文件能自定义什么
items.yml物品名/Lore/图标、研究、9 格配方（可混 VANILLA + SLIMEFUN）
machines.yml耗电机器 + 多条输入输出与耗时
generators.yml发电机产能/缓冲与燃料配方
solar-generators.yml日/夜不同功率太阳能
material-generators.yml按 tick 产出材料
capacitors.yml自定义容量电容
mob-drops.yml生物掉落自定义物
geo-resources.yml群系/维度地质资源
categories.yml / researches.yml指南分类与研究

分类类型支持普通、嵌套父子、季节性（按月）、锁定分类。需求环境见 sc-addon.yml（依赖 Slimefun，MC 版本字段）。详细语法可参考中文附属维基（配置内链接）。
