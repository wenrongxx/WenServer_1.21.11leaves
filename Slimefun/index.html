这是什么，怎么开始玩

Slimefun 4 · 操作手册

粘液科技给原版加了一整棵科技树：新工具、粉碎机、发电机、电缆、货运、机器人、魔法装。所有粘液物品都带专用数据，不能用原版工作台「摆个样子」做出来。

你实际上会做的三件事

  1. 看指南书 → 点研究
    用经验等级买下配方。不研究就做不出来。
  2. 把材料放进粘液机器
    强化工作台摆格子，或把料丢进粉碎机/电炉。
  3. 搭一条自动线
    发电机供电，货运搬箱子，最后做出合金、电路板和装备。

和别的系统怎么接

  • 墓石地牢、结构宝箱挖到的矿和杂物，直接丢进粉碎机/洗矿机扩大收益。
  • mcMMO 刷经验 → 给粘液解锁研究用。
  • 副属分官方附属（花园、灵魂、刷怪笼…）与社区附属（匠魂、美食家、神秘科技…），后文按「怎么做」分开写。

首页 › 第一天操作

第一天照着做

约 30～60 分钟到达第一条半自动产线
  1. 进服收指南书
    首次进入会自动进背包。没有就输入 /sf guide。右键打开，先看「基础」分类。
  2. 做「强化工作台」
    打开指南 → 基础 → 强化工作台 → 看 3×3 格子里要什么（一般是铁砧 + 铁/木板类）。照格子在原版工作台做出这台机器，放地上。
  3. 右键强化工作台
    打开的是粘液专用界面：仍是 3×3 + 结果槽，但只认指南配方。这时才开始做粘液物品。
  4. 解「木棍/基础材料」等 1～2 级研究
    指南里带锁图标的研究：点「研究」→ 若显示「你没有足够的经验」，先去挖矿/打怪升几级再来。1% 会失败，失败就再点一次。
  5. 做出第一把粘液镐或斧
    证明链路通了：研究 → 强化工作台摆格子 → 拿到带粘液 Lore 的工具。
  6. 准备一台粉碎机
    指南里查「粉碎机」所需电路/合金若还不够，先做手磨或更简单的入门研磨（旧版矿研磨机在本服 legacy-ore-grinder: true，指南里有对应配方说明）。

今天不要急着上核电和机器人。先把「研究 → 工作台 → 一台加工机」跑通，比堆一堆半成品机器有用。

首页 › 怎么解锁研究

怎么解锁研究

  1. 打开指南书，进你想做的分类（例如「机器」）。
  2. 点带锁/「已锁定」的物品，在详情页找研究按钮（会显示需要的等级）。
  3. 确认自己等级够：经验栏显示当前等级。不够就先去刷经验（挖矿、地牢、mcMMO 行为）。
  4. 点研究。
    成功：「成功解锁研究 …」+ 可选烟花/学习动画。
    失败（本服 1%）：「研究失败! 你需要再试一次」——等级还在，再点即可。
    经验不足：「你没有足够的经验来解锁这个研究」。
  5. 解锁后再合成。顺序不对时会提示「你的知识还不足以理解这个物品」。

推荐解锁顺序（省经验）

顺序点什么为什么
1强化工作台相关基础没有它后面都点不了
2粉碎 / 洗矿 / 熔炼材料倍增，回本快
3基础电路板几乎全是中后期门槛
4煤发电机 + 电缆进入耗电机器
5背包 1～2 级下矿效率翻倍
6货运节点开始自动化
7按支线果园 / 刷怪 / 匠魂 / 魔法

称号怎么涨

  • 解的研究越多称号越高：小鸡 → … → 学徒 → … → 大师 → 天选之子（共 38 档）。
  • 称号是荣誉展示，不加属性；冲称号就是冲全研究。

本服研究相关硬核项

  • 死亡不会掉研究；全清概率 0%。
  • 费用用经验不是游戏币；多数研究 1～50 级，少数后期更贵。
  • 创造模式可免费解（仅创造/管理场景）。

首页 › 怎么在工作台合成

怎么在强化工作台合成

  1. 指南里打开目标物品，看配方图（3×3 哪一格放什么、数量）。
  2. 右键强化工作台打开界面。
  3. 把材料按格子摆满（有序配方必须位置正确；指南写「无序」才可任意摆）。
  4. 结果槽出现成品 → 点击取出。材料被消耗。
  5. 若结果槽空：
    ① 格子摆错 ② 材料数量不够 ③ 研究未解锁 ④ 你放的是「看起来像」的原版同类物而不是粘液材料。

和原版工作台的区别（必读）

  • 原版工作台做不出粘液装备/机器。指南书上的格子只在强化工作台有效。
  • 自动合成机等机器「不能用粘液物品去套原版合成」——系统会提示不能在合成机上用 Slimefun 物品合成。
  • 多方块机器（冶炼炉等）见下一节，不是点出来的。
分类：合成
首页 › 怎么做多方块

怎么做多方块结构

冶炼炉、高炉类必须「搭」出来
  1. 指南点开多方块机器，看结构示意图（每层放什么方块）。
  2. 准备原版方块（圆石、铁块、漏斗、箱子等，以图为准）。
  3. 找平地，按图一层层摆，注意朝向与空心/实心。
  4. 搭完后对指定核心方块右键（通常会有完成提示或打开界面）。
  5. 接口：输入口放漏斗/箱子，出口对上货运节点或箱子。

在作弊（/sf cheat）里拿不到多方块成品——会提示必须按书中建造。创意服也建议先搭一次记住结构。

  • 搭错排查：少一层、方块种类不对、朝向反了、被楼梯半砖换了。
  • 进阶：冶炼炉链是「矿粉 → 锭」主干；和粉碎机、洗矿机串成线（见 矿石加工线）。

首页 › 矿石加工线

矿石加工线怎么搭

从一箱原矿到一箱锭/粉

目标：挖到的铁、金、铜、锡等尽量变成更多锭 + 副产，再做合金和电路板。

  1. 入口箱：丢原矿、沙砾、矿块。
  2. 粉碎机/研磨：原矿 → 矿粉（通常 1 → 多）。本服矿研磨机为旧版逻辑，洗矿/洗尘为新版。
  3. 洗矿 / 淘金盘：沙砾或矿粉再筛，出小粒金属、宝石、碎料。
  4. 电炉或冶炼炉：粉 → 锭。多方块冶炼炉批量更大。
  5. 出口箱：按金属分箱；废料回入口。
你要做出先走完
粘液合金 / 硬质合金粉 → 熔 → 按指南配比再熔/再合成
基础电路板合金 + 红石类 + 指南格子
高级电路板基础电路板升级，材料见指南
更高级发电机电路板 + 金属外壳，先研究发电类

手动党 vs 自动化

  • 手动：自己开机器界面塞料——前期够用。
  • 半自动：漏斗把入口箱喂到粉碎机，出口漏斗到成品箱。
  • 全自动：见 货运 + 自动合成机。
分类：产线
首页 › 怎么搭电力

怎么搭电力

  1. 做一台煤发电机（或太阳能）：指南 → 发电机分类 → 研究 → 强化工作台。
  2. 放机器，在燃料口塞煤/木炭（界面或漏斗）。
  3. 用粘液电缆从发电机连到要供电的机器。电缆可走地板/墙面，注意别断。
  4. 中间加电容器：发电太多时存着，机器高峰时放出。
  5. 用万用表检查：手持万用表右键机器/电容，会提示「已储存的能源: A / B」。
问题怎么修
机器不转是否连电缆？发电机是否还有燃料？电缆中间有没有断档？
电容总空发电功率 < 耗电：加第二台发电机或升级太阳能
电容总满机器仍饿线太长/没接到该机器；或同时开太多机
网络过大异常本服单网络上限 200，拆成两片并用货运搬能/料
  • 太阳能适合白天产线；夜晚要电池或煤发互补。
  • 核能/放射材料线见 防辐射，不要一上来就堆铀。
分类：电力
首页 › 怎么配货运

怎么配货运网络

  1. 做货运管理器 + 若干货运节点（输入/输出），放在产线旁，管理器供上电。
  2. 贴节点：输入节点贴「有货的箱子/机器出口」；输出节点贴「要收货的箱子/机器入口」。
  3. 右键管理器，新建/选择频道（同一条产线用同一频道）。
  4. 给节点设定：输入端拉出什么、输出端收什么；可加过滤器（只让铁粉过、木棍不过等）。
  5. 空跑测试：丢 1 个物品进输入箱，看几秒后是否到出口箱。
  6. 稳定量产：再把第二条机器接进同频道或新频道。

三条「照抄」模板

模板输入中间输出
矿线矿箱→粉碎粉→洗矿→熔炉锭箱 + 废料箱
农场漏斗收田分拣种子/果实厨房箱 / 种子箱
刷怪塔下漏斗箱过滤灵魂罐材料灵魂箱 / 杂物箱

本服可视化可开，看不清走线就开可视化；多余物品默认不删除，堵了会停——出口一定要有地方去。

首页 › 自动合成机

自动合成机怎么设置

  1. 放一个箱子当「原料箱」。
  2. 把自动合成机放在这个箱子正上方（缺箱会提示：缺少箱子！自动合成机需要被放在一个箱子上方）。
  3. 手持你想要合成的成品，蹲下 + 右键机器。
    提示：「手持你想要合成的物品 蹲下并右键此方块」→ 成功则「成功设置了此机器的合成配方」。
  4. 若「找不到你手持物品的合成配方」：该物可能不能自动合成，或你拿的不是可合成目标。
  5. 启动/停止：对着配方项左键停用/启用；右键删除配方。
  6. 喂料：原料箱塞够材料（甚至含粘液材料），机器按配方自动做，成品通常出现在机内/下方容器（与版本有关，用漏斗接走最稳）。
  • 未解锁研究或物品被禁用时配方不可用。
  • 不要试图用粘液物品去凑原版合成表——会被拒绝。
分类：自动化
首页 › GPS 航点

GPS 与传送怎么做

  1. 做 GPS 设备（手持），在基地设置/添加航点：会提示「给你的路径点起个名字吧」。
  2. 命名成功：「成功添加了新的传送点」。重名会拒绝；最多 21 个。
  3. 需要网络强度时，多放 GPS 信号发射机 提高复杂度。
  4. 复杂度不足时：「GPS 网络复杂度不足」——要么没建网络，要么再放发射机。
  5. 公共点：用 /sf teleporter 看别人公开的点。
  • 死亡会留下死亡点记录（「死亡点 + 时间」），方便捡尸体。
  • 区块加载器（社区附属）每个约吃 7500 复杂度——先攒网络再上加载器。
分类：GPS
首页 › 机器人用法

机器人怎么用

  1. 研究并合成机器人机身 + 程序/部件（指南「机器人/安卓」分类）。
  2. 放在目标区域（矿道、农田、畜栏前），接电。
  3. 右键选择行为：采矿、伐木、农耕、屠宰等（以指南程序为准）。
  4. 设定工作范围与投出方式（往往丢在地上/箱子，上货运收走更稳）。
  5. 观察一小时：产出是否稳定、是否撞到不可挖方块、是否被领地暂停。
  • 领地：无权限区域会「机器人自动暂停」——先要地皮权限。
  • 故障（硬核）：本服概率 0%；若服主调高，故障约 30 秒后自愈。
  • 别把机器人和玩家挤在同一格采同一矿脉，收益会乱。
分类：机器人
首页 › 背包用法

背包怎么用

  1. 合成背包（先研究），拿在手上右键打开，可当移动箱子。
  2. 建议：矿袋 / 农袋 / 药袋分开（染色背包六档可染色，好认）。
  3. 所有者离线时本服仍可打开——别把贵重物放共享背包。
  4. 丢了：管理员或自己用 /sf backpack 相关命令检索找回。
分类：背包
首页 › 护身符怎么用

护身符怎么用

  1. 合成护身符后放进物品栏即可（不需要手持）。
  2. 进行对应行为：挖矿、收菜、打猎、坠落、进岩浆……触发时会弹动作栏提示（本服开启 actionbar）。
  3. 常见搭配：下矿带「矿工」，种田带「农夫/猎人」，探险带「岩浆/水/天使」。

触发是概率性的，不是每块必双倍。多枚可叠放，自己实测收益。

分类：饰品
首页 › 防辐射操作

防辐射操作

  1. 搞铀、钍、核燃料之前，先做防护向防具（指南防护/蜂套类）。
  2. 材料放隔离箱，用货运/漏斗转移，少放玩家背包。
  3. 看动作条：「辐射暴露等级：N/100」。上升就离开材料，利用宽限期（本服 15）。
  4. 本服高暴露会燃烧玩家——别抱一堆铀挂机。
分类：安全
首页 › 异域花园种法

异域花园怎么种

官方附属 · ExoticGarden
  1. 剪草取苗：打草方块/蕨类等，概率掉树苗或灌木（本服树约 22%、灌木约 16%）。把草场当「苗圃」用剪刀/手打一圈。
  2. 种下：和原版树苗一样种在土上，果树会长成带果实的树；灌木直接结果。
  3. 采收：右键/破坏果实或产物，进箱子。
  4. 扩规模：围一块果园，不同品种分区；货运自动收。
  5. 用处：卖给队友、做装饰、供给美食家菜谱（本服异域菜谱开启）。
  • 下界/末地黑名单：别去地狱种。
  • 想要稀有苗：多剪草 + 高草/蕨类（掉率更高）。
分类：官方附属
首页 › 灵魂罐收集

灵魂罐怎么收集

官方附属 · SoulJars
  1. 做灵魂罐（空罐），带在身上。
  2. 击杀配置中的生物（僵尸、骷髅、苦力怕、末影人等绝大多数），灵魂计入罐中。
  3. 目标：每种生物攒到 128（本服统一）即可视为「一满罐」向用途。
  4. 量产：接电力刷怪笼或传统刷怪塔，杀完开罐收。
  5. 满罐拿去合成/交易/做生成向材料（见指南对应格子）。
  • 先专精 2～3 种（如僵尸、骷髅、苦力怕）再横向铺，避免一堆 60/128 的半罐。
  • 村民、远古守卫者等稀有灵更值钱，但来源少。
分类：官方附属
首页 › 电力刷怪笼

电力刷怪笼怎么用

官方附属 · ElectricSpawners
  1. 研究并合成刷怪笼机器，放在封闭杀怪室（防跑怪）。
  2. 选择要刷的生物（本服 25 种：僵尸、骷髅、苦力怕、末影人、岩浆怪、守卫者、村民、女巫、凋灵骷髅…）。
  3. 接电（这是耗电大户，和货运一起上）。
  4. 杀怪方式：手动、全自动击杀脚本/装置、或机器人。
  5. 掉落进漏斗箱 → 货运分拣 → 灵魂罐/战利品箱。
  • 注意实体上限与卡顿；及时清掉落。
  • 和灵魂罐是天然一对：刷怪 = 收灵。
分类：官方附属
首页 › 幸运方块 / 硬核

幸运方块与硬核怎么玩

官方附属

幸运方块

  1. 获取幸运方块（活动/合成/商店，以服务器当时开放为准）。
  2. 放到安全空地再开（避免惊喜爆炸殃及基地）。
  3. 拾取奖励；垃圾可丢，大奖进库。

硬核粘液

  • 解研究时有 1% 失败——等级还在，重试即可。
  • 本服死亡不掉研究；机器人故障 0%。
  • 若服主提高故障率：机器人停 30 秒自愈，别以为坏了拆掉。
