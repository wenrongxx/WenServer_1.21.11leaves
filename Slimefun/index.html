核心玩法（所有附属共用）

解研究

  1. 指南书分类 → 点锁定物品 → 点「研究」，扣经验等级（本服不用游戏币）。
  2. 1% 会失败，失败重试即可；经验不够先去刷级。
  3. 推荐顺序：强化工作台 → 粉碎/洗矿/熔炼 → 电路板 → 发电 → 背包 → 货运 → 分支附属。

强化工作台合成

  1. 原版台先做出「强化工作台」，放地上右键打开。
  2. 按指南 3×3 摆格；有序必须位置正确。结果空 = 摆错/没研究/用错材料。
  3. 多方块机器必须按图搭，/sf cheat 拿不到。

电力与货运

  1. 煤发/太阳能 → 粘液电缆 → 机器；中间加电容；万用表看「已储存能源 A/B」。
  2. 货运节点贴箱子/机器，管理器设频道+过滤；丢 1 个物品测试。网络上限 200。
  3. 自动合成机放在箱子正上方，手持成品蹲下右键设配方。

材料线

原矿 → 粉碎机 → 洗矿/淘金 → 电炉/冶炼炉 → 合金 → 电路板。详细见后文工业附属。

异域花园 ExoticGarden （官方）

打草掉苗，种出奇异果树与灌木，供给美食家与交易。

  1. 用剪刀/手打草方块、高草、蕨类，掉树苗或灌木（树约 22%、灌木约 16%）
  2. 种在泥土上，果树成熟后采果实；灌木直接结果
  3. 围成果园，分区种植；货运自动收
  4. 产物卖给美食家菜谱或玩家

关键物：樱桃/椰子/柠檬/石榴/火龙果树苗、番茄/葡萄/茶灌木。下界/末地不生成。

  4. 满罐 + 铁栏×4 + 土符文×4 + 满罐 → 破损刷怪笼
  5. 破损笼拿去电力刷怪笼修复/升级

关键物：空灵魂罐、满罐、破损刷怪笼。开源 Slimefun-Addon-Community/SoulJars。
