粘液科技（Slimefun）

Slimefun 4 · 2026.07 · 语言 zh-CN · 侧重玩法

粘液科技是 Minecraft 的「科技树」插件：用原版材料在强化工作台等专属机器中解锁新物品、机器、电力与物流。本页覆盖 WenServer 上的 S（主体）、SA 与 SB 附属，重点讲怎么玩，不是完整配方表（配方以游戏内指南书为准）。

配套插件：mcMMO（技能）、墓石地牢等数据包。粘液自定义条目由 SlimeCustomizer 加载。

首页 › 快速入门

快速入门

第一天该做什么

  1. 拿到粘液科技指南
    首次进入会自动赠送（本服 receive-on-first-join: true）。手持右键打开分类目录，也可 /sf guide。
  2. 做「强化工作台」
    绝大多数粘液物品不能用原版工作台合成，必须在强化工作台（Enhanced Crafting Table）按指南书配方摆放。这是整条科技树的入口。
  3. 烧第一块「粘液锭」相关材料
    跟随指南「基础」分类：粉碎矿石 → 洗矿/研磨 → 粘液合金与电路板。前期优先镐、斧、背包与简单发电机。
  4. 攒经验解研究
    许多物品带研究锁：在指南里点「研究」，消耗经验（本服不用游戏币解锁）。研究失败率见「研究系统」。
  5. 搭电力与货运
    煤/太阳能等发电机 → 导电电缆 → 机器；货运节点 + 货运管理器做自动搬运。网络规模上限 200 节点（见配置）。

玩腻了单机式科技树，可以接 灵魂罐（刷怪塔副产）与 美食家 / 异域花园（农食循环），或 粘液匠魂 做工具改造。

首页 › 指南书

指南书怎么用

  • 打开：手持指南右键，或 /sf guide。首次进入自动发放。
  • 分类：材料、工具、武器盔甲、机器、电力、货运、背包、魔法、各附属分类（异域花园、美食家…）。
  • 看配方：点物品进入详情，显示强化工作台 3×3 格子与所需研究。本服开启原版配方对照（show-vanilla-recipes: true）。
  • 搜索：指南内搜索物品名；隐藏物品组默认不在搜索中显示。
  • 与 Wiki 的关系：本网侧重系统与玩法；精确材料格子请以游戏内指南书为准（附属更新后配方可能微调）。

首页 › 研究系统

研究系统

研究是粘液的「科技点」：用经验等级解锁某个配方分支后，才能在强化工作台做出该物品。研究不是消耗材料，而是消耗你的 XP 等级（具体费用随研究等级升高）。

机制本服行为
解锁消耗经验（use-money-unlock: false；若改游戏币，经验换算率 25）
创造模式免费解锁
解锁特效烟花庆祝可开；学习动画默认保留
研究失败（HardcoreSlimefun）1% 失败，失败后可再试
死亡惩罚（HardcoreSlimefun）随机丢研究 关闭；全清研究概率 0%
安卓故障（HardcoreSlimefun）当前故障概率 0%（可由服主调高增加硬核感）

研究称号（research-ranks）

随着累计研究进度会提升称号，大致序列（节选）：

小鸡 → 牛牛君 → 蜘蛛 → 村民 → 开拓者 → 童生 → 实习生 → 学生 → 学徒 → 法师学徒 → 魔术师 → 巫师 → 大师 → 精通大师 → 天选之子

完整称号共 30 余档，以游戏内 config.yml → research-ranks 为准。称号是进度展示，不直接加属性。

首页 › 机器与合成

机器与合成

为什么不能用原版工作台

粘液物品用 NBT/模型区分，配方写在指南书里，必须放进强化工作台等粘液机器的界面。用原版合成表「看起来像」的摆法不会产出粘液物品。

常见机器类型（玩法角色）

类型玩什么例子
合成台把材料做成中间产物强化工作台、装甲锻造台
加工机矿石→粉→锭、合金粉碎机、洗矿机、电炉、冶炼炉
发电机产电，供机器与充能煤发、太阳能、火力、核能（附属）
耗电机用电力加速/合成自动合成台、充电台、3×3 装填
物流箱子与机器自动进出货运节点（输入/输出/高级）、货运管理器
辅助存储、导航、建造背包、GPS、充电站、方块放置

本服 legacy-ore-grinder: true：矿物研磨机使用旧版逻辑；洗矿/洗尘为新版。做自动化前建议先在指南里确认机器是「原版方块 + 木棍/铁砧」类合成，还是需要电路板。

首页 › 电力与网络

电力与网络

电力怎么流动

  1. 发电：发电机产出能量（J），有的带缓冲电容。
  2. 传输：粘液电缆连接成网络；每个网络有规模上限（本服 max-size 200）。
  3. 用电：机器工作耗电；充电台给工具/喷气背包充能。
  4. 缓冲：电容器（含 SlimeCustomizer 自定义电容）削峰填谷，避免发电机空转浪费。

货运（Cargo）

  • 在箱子/机器旁放货运节点（输入 / 输出 / 高级），再用货运管理器设置频道与过滤器。
  • 网络可视化可开（enable-visualizer: true）；超额物品默认不删除。
  • 玩法上：矿石粉碎流水线 → 熔炼 → 入库；农场 → 美食家厨具；刷怪塔 → 灵魂罐。

GPS

航点上限 21。用于传送网络、远程采矿与定位自家基地，和货运网络搭配管理多产线。

首页 › 放射性安全

放射性安全

本服 开启放射性（enable-radiation: true）。铀、钍、部分核材料与成品若不穿戴防护，会持续累计辐射，严重时燃烧玩家（burn-players-when-radioactive: true）。

  • 宽限期约 15 个更新单位；辐射检测间隔 1。
  • 玩法要点：核能向材料放密封容器/背包，穿戴粘液防化/防护套再操作反应堆。
  • 不要把放射性矿物长期丢在地上或塞进无防护仓库。

首页 › SA 附属玩法

SA 附属玩法

生存向扩展 · 采集 / 刷怪 / 背包 / 硬核

异域花园 ExoticGarden

  • 核心循环：破坏草方块/蕨类等掉落树苗与灌木（本服掉率：树约 22%、灌木约 16%，可再乘方块本身的破坏掉率）。
  • 种植后长成樱桃、椰子、柠檬、苹果、石榴、火龙果等奇异果树，以及番茄、葡萄、茶等灌木。
  • 产出服务于美食家烹饪与杂项材料；下界/末地世界黑名单关闭生成。
  • 玩法：开一块「果园产线」+ 货运收集水果，比零散砍草更稳。

灵魂罐 SoulJars

  • 击杀配置中的怪物后，用灵魂罐收集灵魂；每种生物需 128 灵魂（本服统一）。
  • 装满的罐子可做刷怪笼/生成相关材料，也可交易给队友。
  • 玩法：配合刷怪塔/地牢；先专精 2～3 种灵魂（如僵尸、骷髅、苦力怕）再横向扩展。

矿石块 OreChunks + 地质资源

  • 铁、金、铜、锡、银、铝、铅、锌、镁、镍、钴等矿石块地质资源启用。
  • 玩法：地质探矿/矿块粉碎扩产，减少纯靠挖矿的瓶颈。

电力刷怪笼 ElectricSpawners

  • 消耗电力按列表刷怪：僵尸、骷髅、苦力怕、末影人、岩浆怪、守卫者等约 25 种。
  • 玩法：稳定产出灵魂罐材料与战利品；记得接货运与防卡实体。

染色背包 DyedBackpacks

  • 六档全开：小 / 普通 / 大 / 编织 / 镀金 / 辐光。
  • 所有者离线时仍可打开（本服配置）。适合共用仓库谨慎设置权限。

幸运方块 / 硬核粘液

  • 幸运方块：开箱随机奖励，娱乐与资源补充。
  • 硬核粘液：研究有 1% 失败；死亡不丢研究（已关随机丢）；可给机器人加故障（当前 0%）。

SB 附属玩法

制造 / 烹饪 / 魔法 / 战争 / 工具向

粘液匠魂 SlimeTinker

  • 把粘液工具做成可组装、可强化的匠魂风装备：部件、强化槽、材料特性。
  • 玩法：先做一把主武器/主镐，堆 1～2 个核心强化，再换部件而不是整把扔掉。

美食家 Gastronomicon

  • 种植/狩猎掉落种子与特殊食材（草丛约 5～15% 掉率；鱿鱼/守卫者/山羊/鲑鱼击杀约 35%）。
  • 烹饪有概率做出完美食物（上限约 25%）；积累厨师熟练度，256 后解锁机器人相关。
  • 厨师头衔：新手 → 学徒（50）→ 经验丰富（100）→ 三星大厨（200）。
  • 与异域花园联用：不少菜谱要异域水果（本服未禁用该联动）。

神秘科技 FoxyMachines

  • 区块加载器：每人最多 8 个，每个约需 GPS 复杂度 7500。
  • 填充棒：一次最多 4096 格；白名单树叶/玻璃等，黑名单屏障、刷怪笼、命令方块等。
  • 海绵棒：一次最多清 16384 格，适合大范围平整。
  • 可开幽灵方块与自定义怪物（关掉会改部分配方）。

蓬松机器 FluffyMachines

  • 偏便利：自动化工序补全、易用机器。适合接在主产线后面做「最后一公里」。

魔法 Bump

  • 魔法武器与投射物（投射物持续约 10 粘液 tick）。
  • 鉴定系统：按评分给 1～20 星（阈值如 ≥100→20 星 … ≥10→1 星）。
  • 本服语言 zh-CN，研究已开。

战争工艺 SlimefunWarfare

  • 战争向装备与材料（如砷、莫扎石等地质资源）。
  • 玩法：适合基地防御与 PvP 前中期过渡装备。

信息、任务与自定义

  • SlimeHUD：看机器/方块状态，排障产线必备。
  • SlimefunAdvancements：自定义粘液任务线，引导玩法目标。
  • SlimeCustomizer：服主加自定义物品、发电机、机器、生物掉落；参考模板在插件目录。
  • SMG 简易材料生成器：稳定补基础材料。
  • MiniBlocks：迷你装饰方块，建筑党向。
