简介

Slimefun 4 · 2026.07 · 机制百科

粘液科技（Slimefun）将 Minecraft 扩展为无需模组的科技树：材料加工、机器、电力、货运、机器人、魔法与大量附属。所有粘液物品带专用标识，需在强化工作台等粘液机器中按指南书配方制作，不能用原版合成台「拼样子」完成。

本页为机制百科（数值、公式、系统规则）。上手步骤见 玩法指南 专章。

WenServer 运行主体 2026.07 与数十个官方附属、社区附属（含咕咕汉化构建）。研究语言 zh-CN。

分类含义
主体 Slimefun指南书、研究、机器、电力、货运、机器人、背包、护身符、放射性
官方附属异域花园、灵魂罐、电力刷怪笼、工业、捕捉、木龙头、能源等（TheBusyBiscuit / Slimefun-Addon-Community 系）
社区附属匠魂、美食家、Networks、无尽科技、魔法、太空、战争等
  • 与 mcMMO：技能经验可支撑粘液研究解锁。
  • 与 墓石地牢等数据包：地牢材料进入粉碎/洗矿产线。
  • 与 WenServer 材质包：部分粘液/地牢物品汉化贴图。

研究

经验解锁 · 等级成本 · 称号

研究是配方门禁：未解锁则无法合成/使用对应物品。解锁消耗经验等级（本服 use-money-unlock: false；若换算游戏币系数 25）。

机制规则
URID整数唯一研究 ID（Research#getID），存于玩家 UUID 档案
解锁条件player.level ≥ cost 时扣 cost 级；创造免费；PlayerProfile.unlockResearch
cost 本质静态等级数，不是实时公式；代码内无「称号档位」加成
本服 cost 分布约 1～150 级，多数 <50，均值约 22（Researches.yml）
货币字段currency-cost ≈ 25×cost（仅货币解锁时用）
研究失败（硬核）本服 1%（官方默认 10%）
死亡随机丢研究本服关闭
死亡清空全部本服 0%（官方默认 5%）
永久性解锁永久；管理 /sf research 可重置
学习动画 / 烟花可关 / 可开

异域花园 ExoticGarden

官方附属 · 植物扩展

增加奇异果树、灌木与菜肴向产物；与美食家联动。

项机制 / 数值
掉苗破坏草/高草/蕨等；树约 22%、灌木约 16%（再乘方块破坏掉率）

玩法链剪草采苗 → 果园 → 果实进美食家菜谱或交易

开源 Slimefun-Addon-Community/ExoticGarden。

怎么玩：果园从剪草到结果

在草地里剪出树苗/灌木苗，种成水果树和菜。这是最轻松的入门支线，不用机器也能玩。

开始前你要有：剪刀（或空手）、泥土。不需要研究和电力。

  1. 准备一小块地
    找平坦草地挖 2～3 条垄，方便来回采摘。前期不用围栏。
  2. 去剪草拿苗
    对着草方块、短草、高草、蕨挥剪刀或手。破坏后有概率掉树苗或灌木苗（本服树约 22%、灌木约 16%）。高草和大型蕨更值得多打，普通短草掉率低。
  3. 认识苗的名字
    「樱桃树苗」「椰子树苗」会长成树；「葡萄灌木」「番茄灌木」直接结果。名字里带吃的都有用。
  4. 种下
    和原版树苗一样种在土上。树与树隔 2～3 格，太密会挤。灌木可稍密。
  5. 等待长大
    树苗要长一段时间；灌木更快。树苗期别用斧砍。
  6. 采摘
    树上的果实方块打掉/摘下进背包；灌木上的果实同理。这就是你的第一批产品。
  7. 扩大与出售
    做第二块田；水果可以卖给美食家玩家，或自己做菜（见美食家）。想要稀有苗就回去剪高草。
  8. 后期自动化
    产量大了以后，用漏斗/货运接掉落，变成无人值守果园。

新手问题：「剪了半天不掉？」→ 去打高草/大型蕨。下界和末地不会长这些植物，别拿去地狱种。

灵魂罐 SoulJars

官方附属 · 击杀充灵
项机制 / 数值
空灵魂罐水/土/气/火/死灵符文 + 灵魂沙×3 + 空罐

用途电力刷怪笼修复/升级；交易；生成向合成

开源 Slimefun-Addon-Community/SoulJars。

怎么玩：从空罐到满罐

把怪物的灵灌进罐子。灌满一罐（本服 128 只同种怪）就能做出电力刷怪笼的零件。相当于「用击杀存档」。

开始前你要有：能打过的怪、强化工作台、一点合成材料（符文+灵魂沙）。

  1. 在指南搜「空灵魂罐」
    记下配方要的符文种类（水/土/气/火/死灵等）和灵魂沙数量。符文若没解锁，先去解对应研究。
  2. 做出 2～3 个空罐
    一罐只装一种生物的灵，多做几个换着灌。
  3. 罐子放背包即可
    不用拿在手上。只要在你的物品栏，击杀就会开始灌。
  4. 亲手击杀计数
    最好你打出最后一击。被陷阱/摔死/别人抢怪可能不算你的。
  5. 盯着一种怪刷满 128
    本服每种生物都是 128。鸡、僵尸、骷髅好杀，先灌满一种，别摊开 20 种各 10 个。
  6. 做「破损刷怪笼」
    满罐×2 + 铁栏×4 + 土符文×4（以指南为准）。
  7. 用掉或卖掉
    自己接电力刷怪笼，或卖给要自动化的玩家。

建议：第一个罐选僵尸或骷髅。128 很长，专精比摊开快得多。满罐时会有明确的满进度显示。

开源 Slimefun-Addon-Community/ElectricSpawners。

怎么玩：开一间电刷房

通电就刷怪的笼子。配合灵魂罐，变成「自动出怪 + 收灵魂」工厂。

开始前你要有：破损刷怪笼（灵魂罐做）、煤发电机+电缆、封闭小房间。

  1. 搭杀怪室
    用石头围一个 3×3 左右小房间，留 1 格小口方便你砍怪，其余全封死。
  2. 放笼并选怪
    电力刷怪笼放在房间里，右键界面选本服允许的生物（约 25 种）。
  3. 拉电
    约 240 J 才刷一只，缓冲 2048 J。电缆接发电机，建议加电容，否则一停一刷。
  4. 漏斗收掉落
    地板下漏斗 → 箱子。肉、骨头、装备自动进箱。
  5. 开刷与击杀
    怪会持续出现。你在小口砍；记住 4 格内同种怪上限约 6，多了要及时杀。
  6. 同时灌灵魂
    背包放灵魂罐，你杀的同计灵魂。两条线一起涨。
  7. 以后再自动化
    用自动杀怪装置+货运，变成无人车间。

注意实体数量与卡顿；掉落箱满了要清，否则漏斗会堵。

怎么玩：背包装东西、箱保护、抓怪搬家

四种小功能：更大的移动背包、快捷栏宠物、抓怪蛋、只能自己开的私人箱。

开始前你要有：强化工作台；做背包/保护箱的金属材料。

  1. 先做最小的背包
    指南搜背包，按格子做。够装一趟能矿即可。
  2. 用颜色分用途
    一种颜色一个用途（红=矿、绿=农、蓝=药）。染色背包六档容量，后期换大的。
  3. 右键打开背包
    用法和箱子一样。本服离线也能打开——贵重物别全放一个没保护的背包。
  4. 家里放私人箱
    Private：只有你能开/拆。Public：交给领地插件。升级顺序木→铁→钻石→防爆。
  5. 宠物放快捷栏
    宠物物品放在屏幕最下一排快捷栏，再带上它写明的「最爱食物」，效果才持续。
  6. 抓怪当搬家
    捕捉炮装弹丸，对怪射击 → 生物蛋。蛋可带走再放出，保留名字/血量等状态。
  7. 丢了背包
    用 /sf backpack 找回（管理员或按权限）。

新手建议：只做 1 个小背包 + 1 个私人箱就足够前期。宠物等你稳定后再上。

开始前你要有：能搭多方块的材料；已会拉电缆。建议主体已出金属。

  1. 先做「钢转子」
    蒸汽/风力的核心零件，指南搜得到。
  2. 蒸汽轮机怎么搭
    按指南图摆多方块：位置必须在水面上方，正下方有岩浆块。摆错机器不启动。
  3. 看懂功率
    蒸汽三档 8 / 12 / 26 J 每秒；风力 10 / 22 / 46。数字大=给电快。

    高能太阳 512、辐射太阳 1024 J/s；避雷针雷暴时一次 512～8192，当峰值补电。

怎么玩：从一堆箱子到联网仓库

控制器联网后，所有仓变成一个「大超市」：统一搜、统一拿，还能自动合成。类似 AE2/应用能源。

开始前你要有：较多铁/金/电子料；强化工作台；家里已有一堆乱箱子。

  1. 做控制器
    网络主脑，放在仓库中间。一个网络只能有一个控制器。
  2. 用桥铺范围
    控制器覆盖不够时，用桥把网络往外接。
  3. 挂单元当箱子
    「单元」像双箱（54 格）。不够用就做「量子存储」（4096 个起，一直到几乎无限）。
  4. 放网格
    网格=检索窗口：打字搜物品、存取。日常你只开这个界面。
  5. 学会导入/导出
    Import 从普通箱子吸进网；Export 往机器吐。以后矿线、农场全靠它。
  6. 自动合成（进阶）
    配方编码器记住配方 → 自动合成机 64 J/次自动做（Withholding 128 J 可扣留一组）。
  7. 远程器
    四档：150 / 500 / 同维不限 / 跨维。要先在网格绑定，且区块加载。
  8. 清理垃圾
    Purger 设过滤把垃圾清零；量子仓可开「丢弃溢出」防堵。
  9. 取存习惯
    取出：单元 → 扣留合成器 → 贪婪 → 桶。放入：贪婪 → 桶 → 单元。

怎么玩：无底下矿

一种物品能塞几十万甚至无限的便携包；垃圾包则边捡边销毁。

开始前你要有：能合成高阶环/锭；准备长时间挖矿。

  1. 做 T1 Dank 单元
    指南搜 Dank Cell；8 个单元围下界合金块 = Dank 包 1。
  2. 理解槽位与上限
    包 1 只有 1 槽但能装 256 个同种物品。档位升高：槽更多、单槽上限更大（包 9 接近无限）。
  3. 指定槽装什么
    潜行+左键切换槽；把圆石放进槽，之后圆石自动吸进该槽。
  4. 下矿试手感
    挖矿自动吸入。满了会作废多余（红尘提示）——贵重矿用高上限档。
  5. 垃圾包清杂物
    腐肉/种子等设成垃圾，自动作废（琥珀尘提示）。
  6. 从包里放方块
    潜行+右键放纯方块（会留 1），铺路垫脚很方便。
  7. 回家卸货
    Dank 卸货机（每槽留 1）接货运，倒进大仓库。

怎么玩：实用工具怎么用

扳手旋转/改频道、批量合成机、挂机产料、修装备、装饰块。

开始前你要有：基础材料即可。

  1. 新月锤
    右键机器可旋转/拆；点货运节点改频道。冷却 0.5 秒。
  2. FastMachines
    无序配方批量做。本服约 10t 一轮。关用能会改配方。
  3. SMG
    放材料生成器，挂机产基础料。
  4. SlimyRepair
    粘液装备坏了拿去修，别扔。
  5. MiniBlocks / SimpleUtils
    小装饰块；筛子 20% 概率。

ExtraTools 是另一套实用件，按指南拿。

怎么玩：服务与自定义

任务、算料、看机器、消音、村民、液体/光/小世界。

开始前你要有：无特殊前置。

  1. 任务
    打开进度界面，按目标玩，当新手引导。
  2. SFCalc
    输入物品名算总材料——大合成前必用。
  3. SlimeHUD / 消音器
    看机器状态；机器吵就静音。
  4. VillagerUtil
    本服村民魔法要令牌。
  5. 液体/Quaptics/SmallSpace
    罐管输液；光传能传物；小世界超大半径。
  6. SlimeCustomizer（服主）
    YAML 自定义物品机器，reload 后进指南。

新手优先用任务和 SFCalc，其它按需。

玩法指南

操作步骤 · 与机制百科对照

这一章假设你完全没玩过粘液科技。先弄懂三个词：
① 研究：用经验等级买下配方，不研究做不出来。
② 强化工作台：粘液专用合成台，不是原版工作台。
③ J（能量）：机器的电，由发电机供给。

第一天：从零到第一把粘液镐

  1. 进服先看背包
    首次进入会自动送你一本《粘液科技指南》。没有就输入 /sf guide。这本指南就是你的配方书，后面所有物品怎么做都看它。
  2. 右键打开指南
    左边是分类（基础、工具、机器、电力、货运…）。先只看「基础」。里面会写着某物品需要什么材料、在哪个台子做、有没有「研究锁」。
  3. 认识「强化工作台」
    指南里搜「强化工作台」。它通常要铁砧和一些铁/木板（以你游戏内指南为准）。这些材料用原版工作台做——因为强化工作台本身还不是粘液物品。做好后放在地上。
  4. 右键强化工作台
    打开的界面仍是 3×3 格子，但只认指南里的配方。你把材料按格子摆对，右边出成品。原版合成台做不出粘液装备，这是新手最容易卡住的点。
  5. 解第一个研究
    指南里找一把基础镐/斧。若物品上有锁或写「已锁定」，点研究按钮。它会扣你的经验等级（不是钱）。
    · 成功：提示「成功解锁研究」。
    · 失败（本服约 1%）：提示「研究失败! 你需要再试一次」——再点即可，等级还在。
    · 等级不够：去挖几组煤、杀几只怪，或跑一趟地牢再来。
  6. 做出第一把粘液工具
    研究完成后，回强化工作台，按指南格子放材料，取出工具。这时你已经打通「看指南 → 解研究 → 工作台合成」整条链。

第一周：把石头变成电路板（材料线）

粘液的逻辑是：把矿变多，再把多出来的粉变成更高级材料。你以后几乎每个机器都要电路板，所以这条线优先。

  1. 做「粉碎机」类机器
    指南搜「粉碎机」或「矿研磨机」。先做最便宜的那台。它需要你刚才解过的研究和一些金属。
  2. 喂原矿
    打开机器界面，把铁矿/金矿/铜矿放进去。它会慢慢1 矿 → 2 粉（这是粘液倍增矿产的核心）。
  3. 洗矿 / 淘金（可选但推荐）
    「淘金盘」对着沙砾使用，有概率筛出铁粒、金粒、黏土等。「洗矿机」把粉再洗一遍，副产石粉。这一步是「变废为宝」。
  4. 熔成锭
    电炉或冶炼炉把粉 → 锭。2 粉 = 2 锭，所以「粉碎再熔」等于原版挖矿的两倍。
  5. 做合金与电路板
    指南搜「粘液合金」「基础电路板」。配方在强化工作台。高级电路板是后续机器的门票——看到缺它就回这条线补材料。

第二周：让机器自己转（电力 + 货运）

  1. 先做煤发电机
    指南搜「煤发电机」。放好后往里塞煤，它开始产J（能量）。
  2. 拉「粘液电缆」
    电缆把发电机和机器连起来。中间可加「电容」存电（像电池）。
  3. 用万用表检查
    手持万用表对机器/电容右键，会显示「已储存的能源: 当前 / 上限」。机器不转时先看这里是不是 0。
  4. 做货运节点
    「输入」节点贴在「有货的箱子」上，「输出」节点贴在「要收货的箱子/机器」上。再放一台「货运管理器」通电。
  5. 设定同一频道
    右键管理器，建一个频道（比如叫「矿线」）。把输入、输出节点都设成这个频道。丢 1 个矿进输入箱，几秒后看会不会到出口箱。通了再量产。
  6. 接自动合成机（进阶）
    把自动合成机放在箱子正上方。手持你想要的成品，蹲下 + 右键机器写入配方。原料箱塞够料就自动做。

推荐路线图（新手）

  1. 阶段 A
    强化工作台 + 第一把粘液工具 + 粉碎机
  2. 阶段 B
    电炉 + 合金 + 基础/高级电路板
  3. 阶段 C
    煤发 + 电缆 + 电容 + 背包
  4. 阶段 D
    货运一条自动矿线
  5. 阶段 E
    选一条支线玩深：①果园+美食家 ②刷怪笼+灵魂罐 ③匠魂工具 ④Networks 仓储
  6. 阶段 F
    终局：无尽奇点 / 反应堆 / 太空

各附属的「详细玩法」写在对应词条里，会标明你必须先有什么再开始。建议从 异域花园（休闲）或 灵魂罐（战斗向）任选一条入门支线。
