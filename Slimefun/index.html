简介

Slimefun 4 · 2026.07 · 机制百科

粘液科技（Slimefun）将 Minecraft 扩展为无需模组的科技树：材料加工、机器、电力、货运、机器人、魔法与大量附属。所有粘液物品带专用标识，需在强化工作台等粘液机器中按指南书配方制作，不能用原版合成台「拼样子」完成。

本页为机制百科（数值、公式、系统规则）。上手步骤见 玩法指南 专章。

WenServer 运行主体 2026.07 与数十个官方附属、社区附属（含咕咕汉化构建）。研究语言 zh-CN。

分类含义
主体 Slimefun指南书、研究、机器、电力、货运、机器人、背包、护身符、放射性
官方附属异域花园、灵魂罐、电力刷怪笼、工业、捕捉、木龙头、能源等（TheBusyBiscuit / Slimefun-Addon-Community 系）
社区附属匠魂、美食家、Networks、无尽科技、魔法、太空、战争等
  • 与 mcMMO：技能经验可支撑粘液研究解锁。
  • 与 墓石地牢等数据包：地牢材料进入粉碎/洗矿产线。
  • 与 WenServer 材质包：部分粘液/地牢物品汉化贴图。

研究

经验解锁 · 等级成本 · 称号

研究是配方门禁：未解锁则无法合成/使用对应物品。解锁消耗经验等级（本服 use-money-unlock: false；若换算游戏币系数 25）。

机制规则
URID整数唯一研究 ID（Research#getID），存于玩家 UUID 档案
解锁条件player.level ≥ cost 时扣 cost 级；创造免费；PlayerProfile.unlockResearch
cost 本质静态等级数，不是实时公式；代码内无「称号档位」加成
本服 cost 分布约 1～150 级，多数 <50，均值约 22（Researches.yml）
货币字段currency-cost ≈ 25×cost（仅货币解锁时用）
研究失败（硬核）本服 1%（官方默认 10%）
死亡随机丢研究本服关闭
死亡清空全部本服 0%（官方默认 5%）
永久性解锁永久；管理 /sf research 可重置
学习动画 / 烟花可关 / 可开

称号（research-ranks）

小鸡 → 牛牛君 → 蜘蛛 → 村民 → 开拓者 → 童生 → 实习生 → 不合格生 → 学生 → 笨拙学徒 → 学徒 → 熟练学徒 → 法师学徒 → 杰出法师 → 年轻魔术师 → 笨拙魔术师 → 普通魔术师 → 魔术师 → 熟练魔术师 → 特技魔术师 → 惯用魔术师 → 杰出魔术师 → 笨拙巫师 → 巫师 → 普通巫师 → 特技巫师 → 杰出巫师 → 卓越巫师 → 年轻大师 → 笨拙大师 → 实习大师 → 合格大师 → 大师 → 特技大师 → 杰出大师 → 卓越大师 → 精通大师 → 天选之子

称号按累计研究进度递进，纯荣誉展示。本服研究组含主体与数十附属（slimefun 约 258 条 cost 记录，另有 Foxy 41、ExtraGear 32、LiteXpansion 18、美食家 16 等）。

未研究使用提示「知识还不足以理解…需要先解锁」；经验不足提示「你没有足够的经验来解锁这个研究」。

玩法指南

操作步骤 · 与机制百科对照

本章为玩法指南（怎么玩）；机制与数值见上文各百科条目。

上手顺序

  1. 进服 /sf guide 领指南书
  2. 原版台做强化工作台，右键打开
  3. 解基础研究（经验）→ 做第一把粘液工具
  4. 粉碎 → 洗矿 → 熔炼 → 电路板
  5. 煤发/太阳能 + 电缆 + 电容
  6. 货运节点 + 管理器自动化一条线
  7. 按分支：果园/刷怪/匠魂/魔法/太空

产线模板

产线步骤
矿线矿箱 → 粉碎 → 洗矿 → 熔炉 → 锭箱
农场漏斗收 → 分拣 → 厨房/仓

树脂龙头采 → 橡胶厂 → 塑料板

关键操作

  • 研究：指南点锁定项 → 点研究；失败 1% 重试。
  • 合成：只在强化工作台摆 3×3；有序看格子。
  • 多方块：按图搭，cheat 拿不到。
  • 自动合成机：放箱子正上方，手持成品蹲下右键。
  • GPS：设航点攒复杂度，再上区块加载器（≤8，约 7500/个）。
  • 电力刷怪：240J/只，清 4 格内同型 ≤6。
  • 农食：剪草掉苗种果园；烹饪冲熟练度 256。
  • 匠魂：熔金属铸部件，换件不丢强化。
